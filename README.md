# Open WebUI Custom

A customized version of **Open WebUI**, developed for learning, experimentation, and extending an open-source AI platform with additional features.

> **Based on the original Open WebUI project.**

---

## Overview

Open WebUI is a self-hosted AI platform that supports multiple LLM providers including Ollama and OpenAI-compatible APIs.

This repository contains my customized version where I explore AI applications, Docker deployment, REST APIs, and modern full-stack development.

## Installation

Clone the repository:

```bash
git clone https://github.com/vishnuReddi1/open-webui-custom.git
```

Move into the project:

```bash
cd open-webui-custom
```

Run using Docker:

```bash
docker compose up -d
```
